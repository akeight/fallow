# Fallow
**A creative pause companion.**
![Three orbs resting in an open sky](docs/hero.jpg)

## The problem

Designers and other creatives have many tools for making ideas. Almost none protect the empty space the work needs.

## What it is

Fallow is not another place to produce. It is a place to set a thought down.

## On the Mac

Fallow stays beside the work. Say what you are carrying, or type it. Choose how far away you need to get. Press and hold the orb until the thought rests. The desktop stays yours.

## On the iPhone

The same pause, when you are away from the desk. Capture what you are carrying, or sit with a thought that is already resting. It stays in step with the Mac.

## Coming back

When a return was chosen, Fallow sends one gentle nudge. A breath, an open-ended rest, or a night you are running on empty stays quiet. You can let it be for now.

## Where it is

Fallow is in use on my own machines. Coming soon on the App Store for Mac and iPhone.
